Reel Verdict - setup
1. Copy this folder to htdocs (XAMPP) or your I-Drive web folder.
2. Import database.sql in phpMyAdmin (creates the filmreview database).
3. Edit includes/DatabaseConnection.php: host, port (lab used 3307), user, password.
4. Edit includes/config.php: set ADMIN_EMAIL.
5. Make sure the uploads folder is writable.
6. Open index.php.
